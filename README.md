# Digi-PPPiP — Digital Partner Pen Play in Parallel

Digi-PPPiP studies how two partners interact through a shared drawing surface. The repository contains the research manuscript, deterministic computational illustrations, and a React and Socket.IO demonstration. The illustrations and dashboard values are simulated.

- [Documentation](docs/INDEX.md) covers the software, study boundaries, and local checks.
- [Manuscript](docs/manuscript/README.md) and [Template rendering](docs/RENDERING.md) describe the maintained source and reproduction procedure.
